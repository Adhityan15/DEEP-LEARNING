# DEEP-LEARNING


EXPERIMENT NAME

1 . Write a program to build fully connected Feed Forward Neural Network and test the same using appropriate data sets

2 . Build an Artificial Neural Network by implementing the Backpropagation algorithm and test the same using appropriate data sets.

3 . Write a program to implement CNN model (with two layers of convolutions) for handwritten recognition images using MNIST dataset.

4 . Design and implement a CNN model to classify multi category image datasets. Record the accuracy corresponding to the number of epochs. Use the CIFAR-10 datasets.

5 . Train U-NET on a dataset for image segmentation to visualize input images and to segment outputs.

6 . Write a program to implement RNN model with LSTM/GRU for sentimental analysis for movie reviews.

7 . Write a program for text generation using LSTM for character or word level predictions and generate new text sequences.

8 . Write a program to use pretrained BERT model for sentiment analysis in Email communication.

9 . Write a program for realistic image generation using Generative Adversarial Network.

10 . Write a program to implement Continuous Bag of Words Model and Skip gram model using NLP applications

11 . Write a program to build a model that takes an image as input and determines whether the image contains a picture of a dog or a cat.

12 . Write a program to build a Chabot to identify the context the user is asking and then provide it with the relevant answer.

13 . Implement a Variational Autoencoder (VAE) for generating handwritten digits.

14 . Train a simple speech-to-text generative model using an encoder-decoder network.

15 . Build a Super-Resolution GAN (SRGAN) to convert low-resolution images into high-resolution images.


A comprehensive Deep Learning laboratory repository containing 10–12 experiments covering CNNs, U-Net, Image Processing, Optimization, and Model Evaluation using PyTorch
Deep Learning Laboratory

This repository contains a structured collection of Deep Learning laboratory experiments implemented using PyTorch, NumPy, Matplotlib, and related libraries.

The experiments cover core deep learning concepts including neural networks, convolutional neural networks (CNN), image processing, segmentation, optimization techniques, and model evaluation.

🎯 Objectives

Understand fundamentals of Deep Learning

Implement CNN architectures from scratch

Train and evaluate neural networks

Perform image segmentation using U-Net

Apply optimization algorithms

Visualize model predictions and performance metrics
